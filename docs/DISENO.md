# Contrato previsto de Proxy Client

- Boss UI: Install/Uninstall, Enable/Disable y Activate/Deactivate en lugar de Open.
- Launcher y Tray: Activate/Deactivate y Config. Sin ventana principal.
- Config solicita dos veces la IP del Server; la custodia definitiva usa la bóveda propia de Secrets.
- Activate solo en tailnet Stark: valida identidad y endpoint antes de seleccionar Exit Node.
- Deactivate elimina la selección de Exit Node y confirma el estado real.
- Animación Qt de tres segundos: gris a color al activar, inversa al desactivar.
- Los controles personalizados requieren verificar Surface/Lifecycle y capacidades actuales de Boss.
- No se cambia la configuración de red ni se solicita privilegio durante esta fase estructural.
