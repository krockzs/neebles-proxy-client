# Documentación de Proxy Client

`DISENO.md` contiene el diseño general. La fuente, contratos y límites
actuales se describen en el `README.md` de la raíz y en los JSON del módulo.

Los informes previos, ejemplos de política y borradores están conservados
en `history/` como referencia **histórica y no desplegable**. No son
material autorizado de CUSTOM V2 ni políticas aprobadas del sistema operativo.
