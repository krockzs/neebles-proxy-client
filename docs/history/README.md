# Historial de ingeniería de Proxy Client

Los archivos de este directorio corresponden a fases anteriores de 1.0.0,
plantillas o borradores. Se conservan como evidencia histórica, **no** como
contratos vigentes ni como material instalable. Algunos ejemplos contienen
rutas, identificadores o parámetros que ya no representan el diseño final.

Autoridades actuales: `../../README.md` del repositorio (descripción del
producto), `manifest.json`, `lifecycle.json` y `surfaces.json` del módulo.
La autoridad de Construction y los RootFS es NEEBLES CUSTOM V2; las
operaciones privilegiadas requieren aprobación independiente del sistema.
